# User Guide

## First use

1. Install Golishoda Manager and tap **Shops** → **Add shop**.
2. Enter the required shop name. Set its current default bottle price if known.
3. Open **Add Entry**, select the shop, date, and operation type, then enter bottle counts and any payment received.
4. Save. Delivery/return quantities and payments are stored together as one dated ledger entry; a saved price remains fixed for history.

## Daily use

- **Home** summarizes one chosen date and the current combined due, advance, and stock. Quick actions open the entry form.
- **Shops** searches active or archived records. Open a row for balances, stock, recent history, actions, archive, or restore.
- **Daily Supply** moves between dates and lists activity, delivery value, return credit, and collected cash.
- **Reports** filters transaction totals by an inclusive date range and lists current amounts due.
- **Settings** provides backups and CSV downloads.

Sodas In are delivered filled bottles; Sodas Out are empty bottles received back. A return greater than the shop's available chronological stock is rejected; correct the record or investigate stock before saving it. Payments reduce due and can result in advance credit.

## Files and backups

Use each **Export CSV** button to select a destination in the Android save picker. CSV files contain real saved data with headers and quoted/escaped text fields. Create a versioned JSON backup regularly. Restoring explicitly replaces the current shop and transaction records after validation. Backup JSON does not include shop photos.

All business records are local. Uninstalling the app or clearing storage can delete them; keep a backup in a separate safe location.
